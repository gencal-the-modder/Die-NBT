# Die, NBT!
A minecraft mod, which makes so that when you die, NBT tags on items from your inventory get cleared. Per-Item and Per-Mod Configurable!

The skull icon was taken from [Game-icons.net](https://game-icons.net/), though slightly modified by me, and therefore falls under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) license.
